# BolaClip - Código-Fonte Android Completo (Sobreposição Flutuante)

Projeto Android nativo completo do **BolaClip**, pronto para compilação e venda.

## Destaques Implementados
- **Sobreposição Real (`SYSTEM_ALERT_WINDOW` + `WindowManager`):** mantém **apenas** as bolinhas flutuantes e suas caixas de diálogo flutuando sobre qualquer outro aplicativo.
- **Gestos e Limite:** até 30 bolinhas salvas por usuário, rótulo curto de até 4 caracteres, arrastar livre na tela, **1 clique copia**, **2 cliques abre/edita** e **3 cliques salva rápido**.
- **Visual Doce / Confeitaria:** cores pastéis, cantos arredondados e caixa de diálogo compacta.
- **Créditos Oficiais:** exibição da assinatura de **Esteffeson Matheus Barquete** (`barqueteesteffeson@gmail.com` / `54 99329-1661`).
- **Painel Secreto (`Therion@22`):** acessado dentro da caixa de diálogo da bolinha, permitindo configurar URL/chave do Supabase, Token do GitHub (`COLOQUE_SUA_CHAVE_AQUI`), testar adendos e escolher entre **Código Original** ou **Código com Adendos** para envio por e-mail.
